# 🚀 Kenven Service - Professional Services Store

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Languages](https://img.shields.io/badge/languages-HTML%20%7C%20CSS%20%7C%20JS-orange)

A modern, fully-featured services store built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies — just clean, fast, and beautiful code.

## ✨ Features

- 🌐 **Bilingual** — Full Arabic & English support with RTL/LTR switching
- 🌙 **Dark Mode** — Beautiful dark theme with smooth transitions
- 🛒 **Shopping Cart** — Complete cart system with localStorage persistence
- 💳 **Checkout** — Order placement via WhatsApp, Email, or Bank Transfer
- 🔐 **Admin Panel** — Manage services, orders, and messages
- 📱 **Fully Responsive** — Perfect on mobile, tablet, and desktop
- ⚡ **Fast Loading** — Optimized CSS and minimal JavaScript
- 🎨 **Modern Design** — Gradient colors, smooth animations, and glassmorphism
